# Sleep Settlement

Sleep Settlement is an open-source gamified sleep tracking PWA.

The app is designed to turn consistent healthy sleep into visible progress inside a pixel-art settlement. Good sleep helps the settlement grow, while poor sleep damages it through raids and setbacks.

## Core idea

- Track sleep habits
- Reward consistent healthy sleep with settlement growth
- Penalise poor sleep with damage events
- Use a dark, mobile-first interface
- Build as a progressive web app

## Planned tech stack

- React
- TypeScript
- Tailwind CSS
- PWA offline support

## Status

Early concept and planning stage.
